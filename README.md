# A CLI pi calculator

A little bit silly and _useless_ but fun nonetheless.

## Installation
given that you have [go](https://github.com/golang/go) installed, once you've cloned the repo:

```
git clone https://github.com/vilebile17/pi
cd pi
```

You can run `go run .` to run the code in the current repo. However,
it is much more fun and interesting to do a system wide install:

```
go install
```

Now you can calculate pi no matter where in your files you are:

```
pi
```
